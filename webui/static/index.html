生成参数

加速采样使用 ckpts/stage-dmd-step-250，推荐 8 步。
所有方案均可手动调整为 1–100 步；切换预设方案会填入推荐值。
自定义宽高须为 256–2048 的 32 倍数，宽高比为 1:4 至 4:1。
原生 243 帧 · 实际 10.125 秒 · 预计输出 243 帧。
模型原生 24 FPS；其他导出帧率采用抽帧/重复帧，不是运动插帧。按实际时长同步音频。
原生帧数按最接近的 17n+5 对齐（至少 22 帧，15 秒请求对应 362 帧）。时长与帧数为前端估算，最终以服务端校验为准。

高级设置
预设方案自动选择权重；选择“自定义模型”后可编辑路径。
如 npu:0 或 cuda:0。
0 为全部分块卸载；仅在 NPU 且开启分块卸载时生效。不限制帧数，但大帧数/高分块数可能 OOM。
CUDA FP8 是独立的设备优化选项，与加速/标准采样方案无关。
已合并的 rank shard 缓存，跳过 CPU 组装；与 NPU 合并互斥。路径缺失或与 checkpoint 不匹配时会自动生成（约 8–11 分钟）；留空则每次启动都现场组装。默认路径在 /var/tmp，重启服务后仍可复用。
实验性双 NPU TP，支持“分块卸载到 CPU”：retained 保留 CPU 权重，启动快；prefetch 额外预取下一 block，denoise 更快，但每卡需约 36GB pinned host 内存，两卡并发 pin 后首次启动约 38s。首次生成后 worker 常驻，同配置再次生成不再加载模型；同一 prompt 也会复用编码结果。不限制帧数/分辨率，过大仍可能 OOM。NPU 合并启动更快；逐位质量请用 CPU 合并、CPU delta 或缓存。
